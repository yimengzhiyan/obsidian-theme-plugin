## Issues and small fixes

1. **TAB-QA-01 — Radius clipping, FIX VERIFIED.** At Radius 20, active title left-edge pixels and close icon were obscured. Read-only computed evidence showed a 34 px header, 29 px inner, inner `overflow:hidden`, 20 px radius and 20 px native curve. Native curve pseudo-elements use twice the curve for their dimensions; at this value their decoration reaches into control content. Cap the curve and inner radius with `min(var(--theme-workspace-control-radius), var(--theme-space-sm))`; retain the public outer/active Radius mapping and native overflow. Radius 0/20, long titles, close controls and narrow-window retests passed.
2. **TAB-QA-02 — Native active outline overrides indicator, FIX VERIFIED.** Read-only inspection of the actual ordinary root tab found only the native neutral 1 px outline; the lower-specificity Foundation inset indicator was overridden. Add one ordinary-root active selector that preserves the native outline width, consumes `--theme-border-active` for that active header only, and combines the outline with the existing `--theme-indicator` inset shadow. Keep the row/container outline neutral. Final Light/Dark x red/blue/green actual indicator, border and emphasis retests passed.
3. **Scope guard.** Scope P3.1a ordinary refinement selectors to `.mod-root`, preventing inner spacing/surface/close refinements from styling Sidebar tab headers. No Sidebar implementation was added.

Only `src/workspace/tabs.css` changed as source. `theme.css` was generated by Build; `workspace-tokens.css` did not require a fix. No editor/components/navigation/Phase 2 contract changes, DOM patches, runtime, settings, tooltip implementation or animation additions.
